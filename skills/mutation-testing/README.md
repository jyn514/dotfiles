# Mutation testing: attribution and adaptation

This skill and its survivor-analysis reference are adapted from Trail of Bits'
`mutation-testing` skill, workflows, and equivalence guidance at revision
`442fc9d6c89b1e937e6f7a477e7071ea75fcbea4`:
https://github.com/trailofbits/skills/tree/442fc9d6c89b1e937e6f7a477e7071ea75fcbea4/plugins/mutation-testing/skills/mutation-testing

The adapted material retains the upstream **CC-BY-SA-4.0** license; see
[LICENSE](LICENSE). Changes include engine-independent routing, project-owned
execution and isolation, baseline and consumer-path controls, bounded manual pilots,

probes, and integration with the other testing skills. Upstream engine-specific
workflows, evaluation tooling, agents, and assets are not bundled.
