# Resolve applicability before precedence

Use this check when a proposed human decision depends on an apparent conflict between rules or categories.
Read the surrounding explanation, related requirements, documented behavior, and examples.
An apparent omission may be explained elsewhere; distinguish explicit statements from your reconstruction.

Trace both the category and its application.
A source can define a label while an unreviewed agent assessment assigns it to a case.
Identify both origins and any uncertainty that affects the requirement's applicability.

Identify each rule's unit: a word, syllable, stroke, record, or batch, for example.
Check whether the rule or implementation crosses that boundary.
Compare contrasting cases to establish whether both rules apply to the same situation.
For example, *b* is silent in *thumb*, but starts the second syllable in *stumble*.
The same written letters need not make the same rule applicable.
Resolve applicability from the sources before asking which rule takes precedence; ask only about what remains unresolved.
