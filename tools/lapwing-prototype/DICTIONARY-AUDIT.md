# Lapwing dictionary derivation audit

Last updated: 2026-08-29.

> **Correction:** the original missing-word counts compared only exact plain
> JSON values and did not measure Lapwing expressibility. A first Plover rerun
> then retained only one outline per component, compared case-insensitively, and
> incompletely searched composition. Its aggregate counts remain withdrawn. A
> corrected all-outline audit of the final embedded model's 1,513 words absent
> from the reduced US plain-value stack found a conventional full-default-stack
> witness for every word within the stated finite boundary below.

## Corrected model-versus-Plover result

The corrected comparison uses effective dictionary priority and tries every
static reverse outline rather than one representative. Candidates are accepted
only after exact-case execution through Plover's translator and formatter, then
a neutral continuation checks that longest-match processing does not retract or
reinterpret the target. It searches direct entries, suffix and possessive
strokes, attaching prefix/glue entries, ordinary and starred compounds, and
sequences through eight strokes. Letter-by-letter fingerspelling is excluded,
matching the embedded model's conventional-coverage definition.

Against the reduced US stack, 1,509 of the final model's 1,513 generated or
licensed words had a conventional witness. The remaining four were deliberate
UK spelling variants synthesized by the model. Enabling the UK dictionary from
Lapwing's complete packaged default stack supplies exact witnesses for all four:

| Word | Example full-stack witness |
|---|---|
| `favourite` | `TPA*EUFRT` |
| `programme` | `PRAPL/#TPH` |
| `theatre` | `THAO*ERT` |
| `honour` | `HO/TPHOUR` |

Therefore this audit found **no word generated by the final embedded model that
lacks a conventional witness in the complete packaged Lapwing/Plover stack**.
This is a positive-witness result, not a proof over arbitrary configurations:
`user.json` remains external, dynamic/modal dictionaries have unbounded reverse
domains, and outlines longer than eight strokes were not searched. Those limits
do not create an unknown bucket here because every compared word already has a
forward-executed witness inside the finite boundary.

## Withdrawn Plover expressibility rerun

The attempted full-stack rerun is withdrawn. It established several individual
positive witnesses, but its aggregate coverage and negative findings were
invalid. The implementation:

- retained only the first static outline for each component;
- generated candidates from flattened JSON before consulting Python or modal
  dictionaries;
- admitted only target-list words as intermediate composition states;
- stopped composition after three rounds;
- tried only the first three direct outlines for starred compounds;
- approximated Plover orthography during candidate generation;
- compared rendered output case-insensitively despite claiming exact text;
- tested isolated fresh formatter state rather than context, modal transitions,
  or stability across subsequent strokes.

Static keys can also be shadowed by higher-priority executable dictionaries.
For example, base dictionary `SKHR` means “circle”, but the effective default
stack resolves `SKHR` to Emily Symbols' `{#}`. Selecting it as the sole root
witness caused the false claim that “circles” was not found, while these actual
outlines work:

- `SOEURBG/-S` → `circles`;
- `SOEURBG/-Z` → `circles`;
- `SEUR/KAL/KWRES` → `circles`.

The aggregate figures previously reported here—including 41,429 covered words,
7,824 unresolved words, and 122 allegedly model-only words—must not be used.
The generated artifact also contained capitalization mismatches, such as using
a proper-name output as evidence for a lowercase target.

The following individually forward-executed examples remain useful behavioral
checks in the stated isolated formatter state:

| Word | Outline | Mechanism |
|---|---|---|
| `outcome` | `OUT/KOPL` | attaching prefix/glue |
| `outcomes` | `OUT/KOPLZ` | glue plus folded plural |
| `coming` | `KOPL/-G` | Plover orthography |
| `circles` | `SOEURBG/-S` | Plover orthography |
| `days` | `#TKAEU/-S` | attached suffix |
| `playing` | `#PHRAEU/-G` | attached suffix |
| `women's` | `WO/PHEPB/AES` | possessive suffix |
| `world's` | `#WORLD/AES` | possessive suffix |
| `underwater` | `URPBD/#WA/TER` | attaching prefix |
| `favourite` | `TPA*EUFRT` | UK additions |
| `python` | `PAOEU/THOPB` | direct mapping |

A publishable expressibility audit needs a pinned forward-execution harness
that preserves all effective outlines and dictionary provenance, compares exact
case, and searches translator/formatter state rather than composing normalized
strings. It must distinguish “expressible”, “not found within a precisely stated
finite bound”, and “unknown because an executable dictionary has no enumerable
reverse domain”.

## Question

Can Lapwing derive predictable translations instead of enumerating every
outline-to-word mapping, how much could the official dictionaries shrink, and
which English words are absent?

## Benchmark boundary

The audit uses commit `4ac5d53cf039a2b1f4c484456663c85e7df4e859` of
`aerickt/plover-lapwing-aio` and the US lookup stack documented in `README.md`:
commands, numbers, proper nouns, then base. UK additions and dynamic Python
runtime dictionaries are excluded.

The merged stack contains:

- 130,933 outline mappings;
- 125,985 plain lexical mappings;
- 51,910 unique plain lexical translations.

“English words” has no single exhaustive definition. The practical comparison
below uses the pinned `wordfreq==3.1.1` 50,000-row list. Its lexical filter
accepts 49,253 word-shaped entries. A broader dictionary comparison uses the
English Speller Database (formerly SCOWL), American spelling and variant level
1. Names, abbreviations, dialect forms, inflections, and technical terms are
reported separately rather than silently classified as words or nonwords.

## Conclusion

**Yes, but only with exact licensing.** Lapwing can derive spelling from many
outlines and can derive many surface forms from roots. Rules alone cannot decide
reliably whether a generated spelling is intended, resolve collisions, or
preserve every familiar outline. A compact implementation therefore still
needs an exact vocabulary plus exceptions or family certificates.

The safest architecture is the prototype’s current split:

1. shared phonology and orthography derive candidates;
2. grouped morphology licenses root-to-output transformations;
3. an exact vocabulary rejects invented spellings;
4. compact exceptions preserve briefs, irregular spellings, and ordering.

Broadly deleting entries because a word can be synthesized would change outline
compatibility. Deletion is safe only when the original outline itself still
produces the same selected translation under firmware bounds and ordering.

## How much is predictable?

At the firmware-sized 64-candidate frontier, direct rule decoding of the
existing official outlines finds:

| Measure | Result |
|---|---:|
| Existing lexical mappings selected exactly by rules | 41,331 / 125,985 (32.81%) |
| Words with at least one exact official outline | 26,903 / 51,910 (51.83%) |
| Words whose every official outline is selected exactly | 15,059 / 51,910 (29.01%) |
| Words with no exact official rule-derived outline | 25,007 |

The first row is the defensible **mapping-removal ceiling** for the current
rules, vocabulary, candidate order, and beam: about one third of lexical
outline mappings can be reconstructed directly. Removing those mappings from a
canonical compact JSON serialization reduces it from 3,688,955 to 2,611,342
bytes, a 1,077,613-byte (29.21%) reduction. XZ-compressed size falls from
587,056 to 429,928 bytes, a 157,128-byte (26.77%) reduction. These are source
representation measurements, not deployable net savings: an exact searchable
vocabulary, rule tables, and indexes still have to be added.

A separate synthesis experiment builds new outlines from other dictionary
roots and verifies the target under exact vocabulary-prefix pruning:

| Synthesis family | Unique words |
|---|---:|
| Morphology | 16,225 |
| Closed compounds | 6,877 |
| Hyphenated composition | 128 |
| Any of these families | 23,230 / 51,910 (44.75%) |
| Existing mappings belonging to those words | 60,609 / 125,985 (48.11%) |

This 48.11% figure is an **upper-bound opportunity**, not a deletion result.
The synthesized outline may differ from the official outline. Unrestricted
closed-compound splitting can also find accidental analyses such as short
non-morphemic components; exact vocabulary gating prevents invented outputs but
does not make those analyses mnemonic.

The current embedded model demonstrates the achievable storage reduction more
honestly than a record count. It replaces the roughly 3.9 MiB source JSON stack
with 50,959 bytes of linguistic data:

- 4,228 bytes of generated rules;
- 35,394 bytes for a 14,140-word exact LOUDS trie;
- 3,823 bytes for 33 morphology recipes licensing 1,716 roots;
- 7,466 bytes for 1,633 exact exceptions.

That is about a **98.7% reduction from source JSON size**, but it deliberately
does not preserve the complete desktop dictionary. It covers 97.9571% of the
tuned, frequency-weighted first 20,000 types and 91.61% of tokens in the frozen
held-out corpus. It also fits only the measured Moonlander revA image; revB
overflows.

### Dictionary-specific implications

- `lapwing-base.json` supplies most lexical mappings and therefore contains most
  of the derivation opportunity.
- `lapwing-proper-nouns.json` needs exact name licensing and number-bar/case
  semantics. Phonetic rules help, but names are especially exposed to spelling
  ambiguity and collisions.
- `lapwing-commands.json` and `lapwing-numbers.json` are not ordinary lexical
  dictionaries. They should be replaced, where useful, by explicit command or
  numeric grammars rather than included in lexical shrink percentages.
- UK additions can share regular `our/or`, `ise/ize`, `re/er`, and doubled-`l`
  transformations, but were outside this US benchmark.

## Prototype synthesis accuracy audit

This section evaluates the prototype's proposed morphology and unrestricted
string-split algorithms, not the complete Lapwing/Plover stack. In particular,
its closed-compound false positives do not imply that Lapwing's documented
starred-compound mechanism produces those analyses.

There are two different meanings of “accurate” here:

- **output accuracy:** does the generated outline resolve to the intended exact
  spelling? Exact vocabulary gating guarantees this for accepted synthesis;
- **analysis accuracy:** are the claimed root, suffix, or component boundaries
  linguistically genuine? The current generators do not guarantee this.

### Serialized morphology

The byte-identical current model contains 33 recipes licensing 1,716
root-to-output transformations in 3,823 bytes. Of those outputs, 1,207 already
occur in the official stack and 509 are dictionary-absent additions.

The largest families are 767 plural or other `-s` forms, 241 `-ing` forms, 162
`-ed` forms, 82 `-ly` forms, 72 `-er` forms, 59 possessives, and 9 superlatives.
Regular examples include:

- `day → days`, `loss → losses`, and `witness → witnesses`;
- `abandon → abandoning`, `forgive → forgiving`, and `trip → tripping`;
- `pace → paced`, `intercept → intercepted`, and `yield → yielded`;
- `primary → primaries` and `locality → localities`;
- `painful → painfully`;
- `pay → payable`, `tight → tighten`, and `legal → legality`.

However, 112 certificates use roots of only one or two letters and 270 use
roots of at most three letters. The generator treats every configured spelling
ending as potentially productive and chooses compact root/output tails rather
than validating a lemma relationship. Clear accidental analyses include
`r → rage`, `n → nan`, `d → date`, `m → mate`, `he → heist`, `pr → prism`,
`par → parity`, `rot → rotor`, `son → sonar`, and `sir → siren`. Among missing
outputs it also produces name- or informal-token-driven analyses such as
`bad → baden`, `bow → bowen`, `con → conor`, `ig → igor`, `say → sayin`, and
`think → thinkin`.

Thus all 1,716 stored outputs are exact licensed spellings, but 1,716 is not a
count of linguistically sound derivations. A deterministic recipe-stratified
manual audit sampled up to five evenly spaced members from each of the 33
recipes, yielding 162 distinct certificates. It classified 111 (68.52%) as
clearly valid root relationships, 49 (30.25%) as accidental, and 2 (1.23%) as
ambiguous. This deliberately overweights small recipes and is diagnostic, not
an unbiased estimate of all 1,716 certificates. Short-root certificates provide
a mechanical 270-item high-risk review set; derivational suffix families need
lemma evidence before they can be called accurate.

### Closed compounds

After spelling variants and morphology are applied to the 49,253-word
frequency list, closed-compound synthesis adds 3,492 words absent from the
stack. The additions are concentrated in the tail:

| Frequency prefix | New compound-path words |
|---:|---:|
| 1,000 | 0 |
| 5,000 | 5 |
| 10,000 | 35 |
| 20,000 | 309 |
| 49,253 | 3,492 |

A structural audit finds that 1,869 have at least one split whose two
components are both original dictionary words of three or more letters. These
are the strongest automatic compound candidates. Conversely, 1,319 have only
available splits containing a one- or two-letter component and are a high-risk
set. The remaining 304 depend on a synthesized component or have mixed
structural evidence.

Good dictionary-absent results include `outstanding = out + standing`,
`outcome = out + come`, `outbreak = out + break`, `touchdown = touch + down`,
`overtime = over + time`, `underwater = under + water`,
`nonprofit = non + profit`, `superhero = super + hero`,
`blockchain = block + chain`, `storyline = story + line`,
`halftime = half + time`, `lockdown = lock + down`,
`wellbeing = well + being`, and `cybersecurity = cyber + security`.

The same unrestricted spelling split also accepts accidental analyses such as
`programme = program + me`, `stuart = stu + art`, `adelaide = adel + aide`,
`reid = re + id`, `grande = gran + de`, `calif = cal + if`,
`messi = mes + si`, `tamil = tam + il`, and `medicaid = medic + aid`.
Names ending in apparent components, such as `robert + son`, are structurally
valid strings but are not ordinary productive compounds.

A manual review of the 50 highest-frequency compound-generated omissions marked
28 as clearly compositional, 21 as accidental/name/token splits, and one
(`outrage`) as borderline. This 56% sample result is diagnostic rather than an
estimate for the full tail; lower-frequency results contain more names,
abbreviations, and short fragments. Requiring components of at least three
letters would remove many false splits, but would also lose valid productive
prefixes such as `un-`, `re-`, and `in-`. Prefix morphology should therefore be
modeled separately from unrestricted closed compounds.

## Exact plain-value absence (superseded operational metric)

The following comparison asks only whether a word appears literally as a plain
JSON value in the reduced US static stack. It excludes UK additions, glue,
Plover orthography, folded suffixes, fingerspelling, and executable
dictionaries. It remains useful for estimating storage inputs, but it does not
measure whether Lapwing can write the word.

### Common-word comparison

Against the 49,253 word-shaped entries in the pinned frequency list:

| Frequency prefix | Missing types | Present types | Missing estimated frequency mass |
|---:|---:|---:|---:|
| 1,000 | 23 | 977 | 0.71% |
| 5,000 | 184 | 4,816 | 1.16% |
| 10,000 | 717 | 9,283 | 1.64% |
| 20,000 | 2,942 | 17,058 | 2.34% |
| 49,253 | 17,974 | 31,279 | 3.46% |

The full-list type coverage is 63.5%, while estimated frequency mass is about
96.5%. The long missing tail is therefore large by type count but much smaller
in ordinary text.

High-ranked omissions include:

- inflections and plurals: `days`, `playing`, `ended`, `caused`, `americans`,
  `actions`, `nations`, `businesses`;
- possessives: `women's`, `world's`, `today's`, `one's`;
- productive fragments: `non`, `co`, `anti`;
- British forms: `favourite`, `programme`, `theatre`, `honour`;
- names: `angeles`, `sydney`, `ian`, `danny`;
- abbreviations and technical tokens: `usa`, `eu`, `https`, `fbi`, `nba`,
  `cnn`;
- informal forms: `thats`, `didnt`, `alot`.

A conservative suffix audit finds an existing plausible lemma for at least 399
of the top-10,000 misses, 1,432 of the top-20,000 misses, and 5,895 misses in the
complete list. This is a lower bound on productive inflections, not a full
linguistic lemmatization.

The prototype’s broader synthesis pipeline can produce 14,564 of the 17,974
frequency-list omissions when allowed to construct morphology, spelling
variants, compounds, and regular write-out outlines. This is evidence that
many omissions need not be stored as independent outline mappings. It is not
evidence that all generated outlines are desirable or collision-free.

### Broad spelling-dictionary comparison

Against the English Speller Database’s vetted American lists:

| ESDB set | Word types | Missing from Lapwing | Lapwing type coverage |
|---|---:|---:|---:|
| Size 60 | 106,968 | 64,890 | 39.3% |
| Size 70 | 163,570 | 118,948 | 27.3% |

These totals include generated inflections, possessives, names, abbreviations,
and specialist vocabulary. They should not be read as counts of common missing
lemmas. Examples range from ordinary forms such as `abandoning` and `abates` to
names such as `aachen`, and rare words such as `abaft` and `aardwolf`.

Of the 17,974 frequency-list omissions, 10,943 occur in ESDB size 60, 1,089
occur only in sizes 61–70, and 5,942 are outside the American size-70 set. The
last group still includes legitimate British forms, names, initialisms, and
informal language; “outside ESDB” does not mean “not English.”

## Recommended next experiment

Do not attempt another broad suffix table or second word graph. Instead, audit
the 41,331 directly reproducible mappings and measure a complete candidate
format that:

1. preserves the original outline and selected output at beam 64;
2. stores one exact word node shared by vocabulary and exceptions;
3. replaces repeated root/affix mappings with compact family certificates;
4. rejects absent words and ambiguous roots;
5. includes displaced-exception cost in the same fixed-byte optimization;
6. passes byte-identical Python/C tests and both firmware builds.

Prior experiments show that optimistic rule or graph savings often disappear
once exact serialization, candidate ordering, and displaced exceptions are
included. The acceptance metric must therefore be final serialized bytes and
held-out behavior, not the number of apparently derivable words.
